## 문서 갱신 방법

1. 완료한 일은 각 담당 문서의 완료 목록·근거 파일·결과를 함께 갱신한다.
2. 예정인 실험은 완료 목록에 넣지 않는다. 제안·확정·실행 완료를 구분한다.
3. 수치는 실행 코드, 데이터 분할, 설정, seed, 결과 파일과 연결한다.
4. 공용 코드가 다른 브랜치에 있으면 브랜치와 파일 링크를 적는다. 문서 이동만으로 코드가 합쳐졌다고 쓰지 않는다.

이 문서화 작업은 기존 자료의 정리다. 새 모델 학습이나 새로운 팀 합의를 수행한 기록이 아니다.
