### Q-6. 11/25 중간 발표 준비
- 작성: B·정혜원 · 2026-11-18 · 대상: 전원 · 상태: 열림
- 내용: 중간 발표가 2026-11-25로 잡혔다(프로젝트 평가의 30%, [다음 작업 계획](next-tasks-A-B-C-D.md) 기준 "각자 자기 모델·코드·결과를 설명하고 질문에 답하는" 발표).
- 교수님 안내(정혜원 전달, 2026-11-18): 최종 발표가 아니므로 **AI를 써서 실험을 돌렸더라도 각자 자기가 한 것이 무엇인지 질의응답**을 한다. 따라서 결과 숫자보다 **각자 자기 담당 부분을 직접 설명할 수 있는지**가 중요하다. 개인별 준비 예시:
  - 내 모델의 원리(손실함수·하이퍼파라미터가 하는 일)와 그 설정을 고른 이유
  - 내가 실행한 코드의 흐름(입력 → 전처리 → 학습 → 평가)과 결과 파일 위치
  - 결과 해석: 기준선·다른 조건 대비 차이, 신뢰구간, 오분류 원인, 한계
  - AI가 작성한 부분과 내가 확인·결정한 부분의 구분
  
  정할 것:
  - **일정 충돌:** 현재 계획은 11/19~12/14를 작업 미배정 기간으로 두고 있다(AGENTS.md 6절, [README](README.md)). 발표 준비 기간을 따로 둘지, 이 기간을 조정할지.
  - **발표 형식:** 발표 시간, 발표자(전원/대표), 슬라이드 분량과 공통 양식. 공식 요구사항(시간·형식)은 아직 확인 필요.
  - **구성:** 문제 정의 → 데이터·분할(A) → 공통 특징·평가 기준(B·C) → 모델별 결과(A·B·C·D) → 공통 비교표·오류 분석 → 한계와 남은 일. 담당 파트와 순서.
  - **들어갈 결과:** 공통 비교표를 val만 쓸지 test까지 쓸지(Q-1과 연결), 결과 파일을 모으는 방법(Q-2와 연결), 지표 기준(Q-3과 연결).
  - **준비 마감:** 슬라이드 초안·취합 마감일, 리허설 여부.
  - **질의응답 대비:** 서로 예상 질문을 던져 보는 연습을 할지, 각자 자기 결과 문서(`docs/experiments/`)를 설명 자료로 쓸지.
