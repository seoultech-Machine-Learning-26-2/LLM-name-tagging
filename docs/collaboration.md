# 팀 협업 방식

> 상태: 사용자 지정 규칙 · 최종 수정: 2026-11-11 · B/Codex

| 무엇을 하나? | 어디서 하나? |
| --- | --- |
| 각자 코드 구현·학습·실험 | A/B/C/D 각각의 작업 브랜치 |
| 완료 기록·결과 보고·실행 안내 | main 브랜치의 `docs/` |
| 질문·의견·요청·일정 협의 | 카카오톡에서 사람이 전달 |
| 협의 후 결정된 내용 기록 | main의 해당 `docs/` 문서 |

**A·B와 모든 작업을 함께 할 필요는 없다.** 네 명은 같은 A 분할 데이터와 B 공통 특징, C 평가 코드, D 설계·결과 템플릿을 사용하고 자기 모델은 독립적으로 실행한다. 공통 형식을 바꾸거나 다른 사람의 도움이 필요할 때 관련 팀원과 카카오톡으로 맞춘다.

작업 시작 전에 최신 main과 자기 문서를 확인한다. 코드는 자기 브랜치에 저장하고, 문서 정리는 별도로 main에서 진행한다. 실험 코드가 자기 브랜치에만 있으면 결과 문서에서 그 브랜치와 커밋으로 연결한다. 코드의 main 통합은 팀 확인 후 진행한다.

에이전트용 세부 규칙과 역할별 기본 브랜치는 [AGENTS.md](../AGENTS.md)에 있다. 모델별 작업·일정은 [다음 작업 계획](next-tasks-A-B-C-D.md)을 따른다.
