## 2. 문제와 가설

- **문제:** 같은 질문에 18개 LLM이 답한 글에서, 처음 보는 질문의 응답을 보고 작성 모델을 맞힌다.
- **우려:** 사전학습 언어 모델의 문서 표현에는 글의 주제(어떤 질문에 대한 답인지) 정보가 많이 담긴다. 주제 정보가 표현을 차지하면 작성자 문체 단서가 묻힐 수 있다.
- **가설:** 문서 표현에서 주제 정보를 줄이도록 학습하면(주제 적대 학습), 작성자 구분 성능은 유지되거나 오른다.
- **한계 전제:** 이 데이터는 모든 질문에 18개 모델이 한 번씩 답했으므로, 주제만으로는 작성자를 알 수 없다. 주제가 정답 힌트로 직접 새는 구조는 아니다.

## 3. 이론

**DeBERTa-v3-base.** 12층 트랜스포머 인코더다. 단어의 내용과 위치를 따로 표현해 어텐션을 계산하고(disentangled attention), 바뀐 단어 찾기(ELECTRA 방식)로 사전학습했다. 파라미터는 약 1.85억 개다. 사전학습된 가중치 전체를 우리 train으로 다시 학습한다(미세조정).

**구조와 목적함수.**

```
글 → DeBERTa → 토큰 벡터 평균(패딩 제외) → 문서 벡터 z (768)
                                         ├─ 작성자 헤드 (선형, 18)          : L_author = CE(작성자)
                                         └─ GRL → 주제 헤드 (MLP, 105)      : L_topic  = CE(train prompt_id)
전체 손실 L = L_author + L_topic
```

- **GRL(기울기 반전 층):** 순전파에서는 z를 그대로 넘기고, 역전파에서는 기울기에 −λ를 곱한다. 그래서 주제 헤드는 주제를 잘 맞히도록, 인코더는 주제를 맞히기 어려운 z를 만들도록 반대 방향으로 학습된다(DANN 방식).
- **λ = 0:** 인코더로 가는 주제 기울기가 0이라 작성자 분류만 학습하는 **기본형**과 같다. 주제 헤드는 학습되지만 인코더에 영향을 주지 않는다.
- **λ = 0.1:** 작은 강도의 **주제 적대 학습형**.
- **주제 라벨:** train의 `prompt_id`(105개)를 주제 대용으로 쓴다. 실제 의미 주제와 같지 않다. val/test 질문에는 주제 라벨을 쓰지 않는다.

## 7. 모델 분석

### 7.1 과적합과 확률 과신

- train 작성자 손실은 끝까지 내려갔다(λ=0: 2.74 → 0.39). val BA는 기본형이 5에폭, 적대형이 8에폭에 최고였다.
- **val log loss는 두 모델 모두 3에폭에 가장 낮고 이후 계속 올랐다.** 맞히는 개수(BA)는 늘었지만 틀린 글에도 높은 확률을 주는 과신이 커졌다. ECE도 0.24(기본형), 0.35(적대형)로 높다. 적대형은 더 늦은 에폭(8)이 선택돼 과신이 더 크다.
- 에폭 선택을 BA로 했기 때문에 확률 품질은 고려되지 않았다. 확률을 평균하는 팀 앙상블에서는 이 과신이 불리할 수 있다.

### 7.2 적대 학습의 효과

- **주제 정보는 크게 줄었다.** train 주제 진단 정확도 0.494 → 0.201, val 0.732 → 0.581. 학습 중 주제 헤드도 기본형은 0.537까지 맞혔지만 적대형은 0.186에 머물렀다. GRL이 의도대로 작동했다.
- **작성자 성능은 18개 모델 기준으로 차이가 없었다** (+0.0085, 신뢰구간이 0을 포함). 가설 중 "유지된다"는 확인됐고 "오른다"는 확인되지 않았다.
- **개발사 BA는 적대형이 낮았다** (−0.048, 신뢰구간이 0 아래). 특히 Qwen 재현율이 0.318 → 0.091, ZAI가 0.250 → 0.159로 떨어졌다. 단일 seed 결과라 seed 변동일 가능성을 배제하지 못한다.
- 적대형의 val BA 최고점이 더 늦게(8에폭) 나왔다. 주제 신호를 지우는 과정이 학습 속도를 늦췄을 수 있다는 가설이며, 단일 seed라 확인하지 못했다.
- 작성자 진단(train 절반 나누기)은 적대형이 더 높지만(0.944), val 절반 나누기는 둘 다 약 0.24다. train에서 같은 질문 응답을 학습한 표현이라 낙관적인 진단이다.

### 7.3 혼동 분석 (적대형 λ=0.1 기준, 기본형도 경향 비슷)

- **개발사 재현율:** Google 0.955, Anthropic 0.864, OpenAI 0.800, Moonshot 0.227, ZAI 0.159, Qwen 0.091. 모델 수가 많은 개발사로 끌려간다.
- **모델별 재현율:** `glm-5.3`은 두 모델 모두 0. 가장 높은 모델은 `claude-opus-4-6` 0.773, `gemini-3.1-pro-preview` 0.727.
- **"흡수" 클래스:** `gpt-5.6-luna`와 `claude-opus-4-6`으로 다른 모델이 많이 몰린다. 주요 오분류 쌍: `gpt-5.6-sol` → `gpt-5.6-luna` 12, `qwen3.8-max` → `gpt-5.6-luna` 11, `gemini-3.7-flash` → `gemini-3.6-flash` 11, `claude-sonnet-5` → `claude-opus-4-6` 9.
- 오류 266개 중 57.5%가 같은 개발사 안의 혼동이다(기본형 58.0%). RF(42.6%)보다 높다. DeBERTa가 개발사는 더 잘 맞히고, 남은 오류가 형제 모델 구분에 몰린다는 뜻이다.

## 8. 결론·한계

**확인한 점**
- DeBERTa 미세조정은 val 18개 모델 BA 0.32~0.33으로, 같은 분할의 RF(0.205)와 C TF-IDF 기준선(0.290)보다 높았다. 개발사 BA는 0.52~0.56.
- 주제 적대 학습은 문서 표현의 주제 정보를 절반 이하로 줄였지만, 작성자 성능은 18개 모델 기준으로 유의한 변화가 없었고 개발사 기준으로는 낮아졌다.
- 남은 오류는 같은 개발사 형제 모델 사이에 몰리고, 확률은 과신한다.

**한계**
- seed 1개라 두 조건의 차이와 seed 변동을 구분하지 못한다. 계획상 최종 후보는 seed 42/43/44가 권장된다.
- 에폭 수(5 → 10)와 에폭 선택에 val을 사용해 val 점수가 낙관적일 수 있다. val 질문이 22개라 신뢰구간 폭이 약 0.11이다.
- λ는 0과 0.1 두 값만 비교했다. deberta-v3-large는 시간·GPU 메모리 제약으로 시도하지 않았다.
- 주제 라벨은 `prompt_id` 대용이며 실제 의미 주제와 다르다.
- 6~8절은 응답 단독 예측이다. 질문 중심화(질문 묶음 이용) 결과는 10절에 따로 적는다. 헝가리안 배정은 쓰지 않았다(팀 앙상블 단계에서 다룸).

## 10. 질문 중심화 (2026-11-21, 질문 묶음 이용)

2026-11-18 회의 결정(질문함 Q-10 결정 2: 4명 모두 질문 중심화 적용)에 따른 추가 실험이다. A는 심화 모델(DeBERTa)에만 적용했다(고전 RF는 적용하지 않음, 사용자 결정). 적용 규칙은 질문함 Q-11을 따른다.

### 10.1 방법

- **질문 배치:** 배치 하나 = 같은 `prompt_id`의 응답 전부(18개, train의 한 질문만 17개). 1에폭 = 105배치. 6~8절의 기존 실행은 응답을 무작위로 섞어 16개씩 묶었다.
- **질문 중심화:** 문서 벡터 z에서 같은 배치(= 같은 질문) 응답들의 평균을 빼고, **[z ; z − 질문 평균]**(1,536차원)을 작성자 헤드에 넣는다. C Qwen·B ModernBERT와 같은 형태다. 평균은 각 분할 안에서 같은 질문의 응답끼리만 계산하고 정답(`model`)은 쓰지 않는다. val도 질문 단위로 묶어 예측한다.
- **주제 적대 학습(GRL):** 기존과 같이 중심화 전 z에 건다.
- **나머지 설정:** 6~8절의 10에폭 실행과 같다(인코더 lr 2e-5, 헤드 lr 1e-3, 최대 10에폭, val BA 최고 에폭 선택, 3에폭 연속 개선 없으면 조기 종료, seed 42, 최대 512토큰). test는 읽지 않았다.

| 조건 | 배치 | 중심화 | λ | 목적 |
| --- | --- | --- | --- | --- |
| 기존 λ=0 (6절) | 무작위 16개 | 없음 | 0 | 기준 |
| ③ `qb_nocenter_lam0` | 질문 하나 | 없음 | 0 | 배치 방식만 바꾼 대조군 |
| ① `qb_center_lam0` | 질문 하나 | [z ; z − 평균] | 0 | 중심화 효과 |
| ② `qb_center_lam0.1` | 질문 하나 | [z ; z − 평균] | 0.1 | 중심화 + 주제 적대 학습 |

실행: Kaggle Tesla T4, `eunjin` 코드 커밋 `54b5800`, `notebooks/A_deberta_centered_kaggle.ipynb`. 환경은 1절과 같다(Python 3.13.16, torch 2.11.0+cu130, transformers 5.20.2).

### 10.4 해석

- **배치 방식만 바꾼 효과는 없었다** (③ − 기존, 신뢰구간이 0을 포함). 따라서 ①의 향상은 질문 배치가 아니라 중심화에서 온 것으로 본다.
- **질문 중심화는 18개 모델 BA를 +10.5%p 올렸다** (0.306 → 0.409, 신뢰구간이 0보다 큼). 개발사 BA(+8.1%p)와 형제 정확도(0.410 → 0.521)도 올랐다. 같은 질문 응답들의 공통 부분(주제·질문 형식)을 빼면 모델 사이 차이가 더 잘 드러난다는 C 문서의 설명과 맞는다. 다른 역할의 같은 비교: C Qwen LoRA +15.4%p, B ModernBERT +3.4%p (각 문서 기준, 모델·학습 방식이 달라 직접 비교하지 않는다. 질문함 Q-12).
- **확률 품질도 좋아졌다.** Log loss 2.54 → 1.82, ECE 0.28 → 0.17. 6~8절의 과신 문제가 줄었다.
- **중심화 상태에서 주제 적대 학습(λ=0.1)은 오히려 낮췄다** (−3.5%p, 신뢰구간이 0 아래). 가능한 원인(가설):
  - 질문 배치에서는 배치 안의 주제 라벨이 모두 같아, 주제 헤드가 거의 배우지 못했다(학습 중 주제 헤드 정확도 0.01~0.03, 6절 기존 실행 0.19~0.54). 그 결과 GRL이 주는 신호가 주제 정보를 지우는 방향이라기보다 잡음에 가까웠을 수 있다.
  - 실제로 문서 벡터 z의 주제 진단 정확도(train 절반 나누기)는 ① 0.734, ② 0.759로 줄지 않았다. 중심화가 이미 작성자 헤드 입력에서 질문 평균을 빼므로, z 자체의 주제 정보를 지울 필요도 작다.
  - 단일 seed라 seed 변동일 가능성도 있다.
- **중심화 모델은 z에 주제 정보를 더 많이 남겼다** (z 주제 진단 train ③ 0.534 → ① 0.734). 작성자 헤드가 질문 평균을 뺀 값을 받으므로, 인코더가 z에서 주제를 지우도록 압박받지 않기 때문으로 본다.
- **에폭 4의 0.409는 앞뒤 에폭(0.336, 0.361)보다 크게 높다.** val BA로 고른 최고 에폭이라 낙관적일 수 있다. 다른 에폭도 0.33~0.36으로 ③(최고 0.306)보다는 모두 높다.

### 10.5 혼동 분석 (① 중심화, val)

- 개발사 재현율: Google 0.966, OpenAI 0.864, Anthropic 0.800, Moonshot 0.409, ZAI 0.364, Qwen 0.227. 모델이 적은 개발사도 기존(Moonshot 0.227, ZAI 0.250)보다 나아졌다.
- 재현율이 낮은 모델: `gpt-5.6-terra` 0, `glm-5.3-flash`·`gemini-3.8-flash`·`gpt-5.5` 0.182. 높은 모델: `gemini-3.6-flash`·`claude-opus-4-6` 0.727.
- 주요 오분류 쌍: `gemini-3.8-flash` → `gemini-3.7-flash` 10, `gemini-3.7-flash` → `gemini-3.6-flash` 10, `claude-sonnet-5` → `claude-opus-4-6` 8, `claude-opus-5` → `glm-5.3` 8, `gpt-5.6-sol` → `gpt-5.6-luna` 7.
- 오류 234개 중 58.1%가 같은 개발사 안의 혼동이다. 중심화 뒤에도 남는 오류는 형제 모델 구분에 몰린다.

### 10.6 한계

- 응답 하나만 주어지는 상황에서는 쓸 수 없다. 같은 질문의 응답 묶음이 있어야 한다(계획 4절 9번: 응답 단독 예측과 구분해 적는다).
- seed 42 하나다. 조건 간 차이(특히 ② − ① −3.5%p)는 seed 반복으로 확인해야 한다.
- 중심화는 질문 배치를 전제로 해서, λ>0의 주제 적대 학습이 6절과 같은 방식으로 작동하지 않았다. 질문 배치에서 적대 학습을 하려면 배치에 여러 질문을 섞는 등 설계를 바꿔야 한다.
