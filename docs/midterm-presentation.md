## ⑥ ⭐ 핵심 발견: 질문 중심화 · `60초`

**🖥️ 화면**

- 같은 질문 응답 18개의 평균을 빼서 주제 영향을 줄임 (정답 라벨 안 씀)
- **7개 모델 모두 +3.4 ~ +15.4%p**
- 조건: 같은 질문의 응답 묶음이 있어야 함

**🖼️ 그림**

- 아래 표로 만든 전·후 막대그래프

| 담당 | 모델 | 응답 단독 | + 중심화 | 변화 | 확인 방법 |
|:---:|---|:---:|:---:|:---:|---|
| A | DeBERTa | 0.306 | **0.409** | 🔼 +10.5%p | 신뢰구간 [5.6, 14.9] |
| B | Linear SVM | 0.301 | **0.386** | 🔼 +8.6%p | 신뢰구간 [4.8, 12.9] |
| B | ModernBERT | 0.346 | **0.380** | 🔼 +3.4%p | 신뢰구간 [0.3, 6.2] |
| C | XGBoost | 0.258 | **0.381** | 🔼 +12.3%p | 5-fold (0.294 → 0.344) |
| C | Qwen LoRA | 0.328 | **0.482** | 🔼 +15.4%p | seed 42 결과. 이후 V3를 seed 3개로 반복해 0.485 ± 0.007 유지 |
| D | LR | 0.338 | **0.408** | 🔼 +7.0%p | 신뢰구간 [2.8, 11.4] |
| D | SBERT 융합 | 0.248 | **0.353** | 🔼 +12.5%p | 신뢰구간 [8.6, 16.4] |

> [!NOTE]
> - 각 모델 안에서 전·후를 비교한 표 (**모델 간 순위 비교용 아님**)
> - A·B 심화 모델은 배치 방식만 바꾼 대조군과 비교 (배치 효과를 빼려고)
> - 신뢰구간은 질문 단위 paired bootstrap 95% · RF 미적용
> - **D의 LR 실험은 정규화 파라미터 `C`를 고정하지 못한 한계가 있음.** 따라서 결과를 중심화만의 순수한 효과로 단정하기 어렵고, 동일 `C` 조건에서 재검증할 필요가 있음

> [!TIP]
> **🎙️ 말할 것** · 배경 → 방법 → 결과 → 한계 순서
>
> **배경:** 질문마다 18개 모델이 한 번씩 답한 구조 → 같은 질문 안 1:1 배정만으로 0.290 → 0.404 → EDA의 질문별 평균 보정을 입력 단계에 적용 → 고전에서 확인, 5-fold 재확인 → 심화 → 팀 전체
>
> **핵심 문장:** "같은 질문의 응답 묶음이 주어지는 조건에서, 질문 중심화를 적용했을 때 7개 모델 모두 val 성능이 올랐습니다."
>
> **주의:** LR은 `C`가 고정되지 않았으므로 개선 원인을 추가로 검증해야 함

## ⑪ ⭐ 추후 개선사항: 앙상블 · `25초`

**🖥️ 화면**

### 서로 다르게 틀리는 모델을 결합하면 더 정확하게 구분할 수 있을까?

| 개선 방향 | 방법 | 기대 효과 |
|---|---|---|
| **① 모델 앙상블** | Qwen·DeBERTa·ModernBERT 등 서로 다른 모델의 예측 확률 결합 | 모델별 오류 보완 |
| **② 앙상블 가중치 조정** | 균등 평균과 가중 평균 비교 | 모델별 기여도 반영 |
| **③ 실험 조건 통일** | seed 수·epoch 선택·확률 보정·결합 방법 통일 | 신뢰할 수 있는 비교 |
| **④ 형제 모델 구분 개선** | 혼동이 잦은 모델 쌍의 예측 및 문체 차이 분석 | 같은 개발사 내부의 오분류 감소 |

> [!NOTE]
> **C 개인 앙상블 예비 실험**
>
> - 당시 실험: Qwen 단일 **0.492** → 6개 앙상블 **0.548** (+5.6%p)
> - 개발사 BA **0.705** / 모델 BA **0.548**
> - 다만 이는 **C 개인의 예비 실험 결과**이며, 팀의 최종 앙상블 성능이나 채택 결과가 아님
> - 현재 중간발표 채택 결과는 **Qwen 단일 0.482**
> - 당시 단일 모델 0.492와 현재 채택 결과 0.482는 실험 조건이 완전히 동일한 비교라고 보장할 수 없으므로 직접적인 성능 비교는 지양
> - 추후 팀원들의 예측 파일과 실험 조건을 통일한 뒤 앙상블 효과를 재검증할 예정

> [!TIP]
> **🎙️ 말할 것**
>
> "지금까지는 개별 모델의 특징과 개선 효과를 확인했습니다. 앞으로는 서로 다른 모델이 틀리는 패턴을 분석하고, 예측을 결합하는 앙상블을 실험하려고 합니다. 특히 형제 모델을 더 잘 구분할 수 있는지 확인할 계획입니다."
>
> **발표 시 주의:** 예비 실험의 0.548을 최종 확정된 앙상블 성능으로 소개하지 않기
