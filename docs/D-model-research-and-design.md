# [D] 모델 조사 및 실험 설계

> 상태: 기존 조사·설계 완료 · 담당: 하람(D) · 문서 이관: 2026-11-11 · B/Codex

## 1. 완료한 일

- 고전 기계학습 모델 4개와 심화 모델·기법 4개를 조사했다.
- 1인당 고전 모델 1개와 심화 모델 1개를 맡는 기존 배정안을 작성했다.
- 동일 분할·동일 평가 데이터로 비교하는 실험 방향을 정리했다.
- 실험 개요부터 특징 분석·최종 결과·산출물까지 기록할 결과 템플릿을 정의했다.

원래 노션 상태는 **진행 완료**다. 여기서 완료는 **모델 조사와 실험 설계**를 뜻한다. 아래 모델의 구현·학습·성능 검증이 완료됐다는 뜻은 아니다. 출처는 이 대화에서 앞서 읽은 노션 내보내기의 `[D] 모델 조사 및 실험 설계`와 결과 템플릿이다. 원본 압축파일은 이관 시 기존 경로에 없어 재열람하지 못했으며, 앞서 확인한 내용을 기준으로 기록했다.

## 2. 기존 모델 배정안

| 기존 번호 | 고전 모델 | 심화 모델·기법 | 조사한 접근 |
| --- | --- | --- | --- |
| 1 | Random Forest | DeBERTa-v3-base + 주제 적대 학습 | 작성 모델은 구분하면서 주제 정보 의존을 줄이는 학습 |
| 2 | Linear SVM | ModernBERT-base + 대조 학습 | 같은 작성 모델의 표현을 가깝게, 다른 작성 모델은 멀게 학습 |
| 3 | XGBoost | Qwen3.5-0.8B/2B + LoRA | 일부 추가 파라미터를 학습해 분류에 활용 |
| 4 | Logistic Regression | Sentence-BERT + Stylometric Fusion Network | 의미 임베딩과 문체 통계를 결합 |

이는 당시 설계 기록이다. 모델명·가용성·버전·하드웨어 적합성을 이번 이관에서 새로 검증한 것은 아니다. 현재 실행할 담당·범위는 [다음 단계 계획](next-tasks-A-B-C-D.md)의 최신 내용을 별도로 확인한다. 기존 조사와 새 강의 중심 계획이 섞이지 않도록 이 표를 유지한다.

## 3. 조사한 고전 모델

| 모델 | 핵심 원리 | 당시 활용 구상 |
| --- | --- | --- |
| Random Forest | 여러 결정트리 예측을 합치는 앙상블 | 길이·문장부호 등 문체 특징과 중요도 분석 |
| Linear SVM | 클래스를 구분하는 경계의 여유 폭을 크게 학습 | TF-IDF 기반 단어·표현 패턴 분류 |
| XGBoost | 앞선 예측 오차를 순차적으로 보완하는 트리 부스팅 | 문체 특징 사이 비선형 관계 학습 |
| Logistic Regression | 특징의 가중합을 클래스 확률로 변환 | 특징 계수의 크기·방향 해석 |

이론 소개는 선택 이유를 설명하는 조사 결과다. 이 데이터에서 어느 모델이 더 좋다는 실험 결론이 아니다.

## 4. 조사한 심화 기법과 주의점

| 기법 | 목적 | 원문에 남긴 주의점·가정 |
| --- | --- | --- |
| 주제 적대 학습 | 주제가 바뀌어도 남는 작성 스타일 학습 | 원문은 별도 주제 라벨링 가능성을 언급; C는 `prompt_id` 활용을 제안함 |
| 대조 학습 | 작성 모델별 표현의 유사성과 차이 학습 | 사전학습 모델 활용, 분류 확률 출력은 별도 구현 필요 |
| LoRA | 큰 모델의 일부 파라미터만 추가 학습 | 0.8B 기본, 2B는 시간에 따른 선택 실험 |
| 의미·문체 융합 | 두 종류 특징의 결합 효과 확인 | 의미만·문체만·융합을 나눠 비교해야 함 |

현재 과제 방향에서는 고전 모델의 이해·통제 실험·오류 분석을 우선하고, 심화 모델은 선택 확장으로 두는 새 제안이 있다. 위 조사를 삭제하거나 이미 실행한 것으로 바꾸지 않는다.

## 5. 기존 실험 공통 원칙

모든 모델은 A의 같은 Train/Val/Test 분할을 사용한다. 고전 모델은 가능한 한 동일 공통 특징으로 비교하고, 심화 모델은 학습 목적이 달라도 같은 평가 데이터와 지표를 사용한다. 결과는 개발사 6개와 개별 모델 18개를 각각 평가한다.

기존 결과 템플릿은 **Validation Macro F1**을 최종 선택 기준으로 적었다. 이후 C 자료는 **Validation BA**를 기준으로 제시한다. 문서 이관만으로 하나를 확정하지 않았으며 팀 기준 확인이 필요하다. 새 보고서에는 실제 사용한 선택 지표를 명시한다.

## 6. 결과 템플릿 정의

원본 구조는 다음과 같다.

1. 실험 개요: 담당자, 모델, 구분, 날짜, 실행 환경.
2. 실험 설정: 데이터·분할·seed, 전처리·특징, 설정 탐색·선택 기준.
3. 학습 결과: 개발사/모델별 val·test 지표, 학습 시간·선택 모델.
4. 모델 분석: 혼동행렬, 특징 중요도·계수, 오분류 사례.
5. 심화 추가 실험: 사전학습 모델·기법, 적용 전후 비교.
6. 최종 요약: 핵심 결과·장점·한계.
7. 산출물: 코드, 체크포인트, 결과 CSV, 그림, 보고서 위치.

[복사해서 쓸 Markdown 템플릿](experiment-result-template.md)을 별도 파일로 만들었다. 원본 구조를 유지하면서 과제 공지의 환경 첫 문항 요구와 C의 BA 항목을 표시하고, 심화 실험은 선택 항목으로 구분했다. 원본을 그대로 복제한 파일이 아니라 사용 목적에 맞춘 정리본이다.

## 7. 다음에 확인할 것

- 기존 심화 모델 계획과 새 강의 중심 계획의 필수·선택 범위를 팀에서 확인한다.
- 모델 선택 기준·개발사 평가 방식을 C와 맞춘다.
- 각 담당자는 자기 모델 이론·코드·결과·한계를 작성하고, 통합 담당자는 이를 공통 보고서 형식으로 모은다.
- 최종 결과는 실제 실험 후 작성한다. 원본의 `최종 결과` 페이지도 전체 실험 종료 후 작성 예정이었다.
